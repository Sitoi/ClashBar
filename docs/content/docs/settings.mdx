偏好、自启、端口与维护操作集中在「设置」标签。可用 <kbd>⌘,</kbd> 或 <kbd>⌘⌥5</kbd> 直接打开（ClashBar 在前台时）。连接**远程机器**时，部分开关会标明仅作用于本机。

系统代理与 TUN 的使用边界见 [系统代理与 TUN](./network-mode)；完整能力索引见 [功能总览](./features)；快捷键见 [日常使用 · 键盘快捷键](./daily-use#键盘快捷键)。

## 基础 / 应用设置

| 选项 | 说明 |
| --- | --- |
| 开机自启 | 登录 macOS 时启动 ClashBar（需在 `.app` 环境中；可能要求登录项批准） |
| 内核自启 | 应用启动后自动启动 mihomo |
| 状态栏样式 | **图标 + 速度** / **仅图标** / **仅速度** |
| 界面语言 | 简体中文 / English |
| 外观模式 | 跟随系统 / 浅色 / 深色 |
| 日志级别 | 覆盖内核 `log-level`（如 info、warning 等） |

### 代理绕过

在设置中展开 **代理绕过**，可维护写入 macOS 系统代理的例外列表：

- 支持主机、域名、CIDR 或 `<local>`。
- 支持新增、删除、**恢复默认**、**保存**。
- 重新开启系统代理时会继续使用已保存列表。

详见 [系统代理与 TUN](./network-mode)。

## 内核设置

下列开关通过运行时 patch 作用到当前控制的内核（远程时作用于远程实例）：

- **允许局域网**
- **IPv6**
- **TCP 并发**

## 代理端口

可编辑并应用：

- HTTP 端口
- SOCKS 端口
- 混合端口
- 重定向端口
- TProxy 端口

合法范围为 0–65535。修改后会按应用逻辑自动保存/同步；系统代理开启时可能触发端口同步。复杂监听与入站策略仍建议在 YAML 中维护权威配置。

## 系统维护

| 操作 | 说明 |
| --- | --- |
| 清理 FakeIP 缓存 | 请求内核清理 FakeIP 缓存 |
| 清理 DNS 缓存 | 请求内核清理 DNS 缓存 |
| 更新 Geo 数据库 | 内核**运行中**时可更新 GEO 资源 |
| 打开内核目录 | 在访达中打开 `…/clashbar/core` |

面板页脚另提供 **升级 Core**（检查/更新 mihomo）以及应用版本更新提示（若检测到新版本）。

## 网络与内核联动

- 检测到**网络断开**时，可将内核停止；**网络恢复**后可按策略自动再启动（与内核自启等设置配合）。
- 具体行为以当前版本日志中的「网络断开 / 网络恢复」记录为准。
