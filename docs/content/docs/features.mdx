本页按**真实产品界面与能力**梳理 ClashBar 能做什么。每一项都对应菜单栏面板、设置或快捷操作中的实际入口；需要操作步骤时，请跟随右侧链接进入专题页。

> 范围说明：这里覆盖用户可感知的产品能力（标签页、内核、配置、网络接管、远程控制、排障与维护等），不展开私有实现细节，也不替代完整的 Mihomo YAML 参考手册。

安装推荐使用 **Homebrew**（`brew install --cask clashbar`）或 GitHub Releases；含 Core / 无 Core 构建与注意事项见 [快速开始](./quick-start)。配置目录仅识别 `.yaml` / `.yml`，并按**文件名排序**加载，见 [配置与订阅](./configuration)。

## 界面结构

| 能力 | 说明 | 文档 |
| --- | --- | --- |
| 菜单栏面板 | 点击状态栏图标打开原生面板，集中管理配置、节点、规则、连接、日志与设置 | [日常使用](./daily-use) |
| 面板固定 | 将面板固定在屏幕上，切换其它应用时不自动关闭 | [日常使用](./daily-use) |
| 状态栏样式 | 仅图标 / 仅速度 / 图标 + 速度，展示上下行速率 | [设置与维护](./settings) |
| 外观与语言 | 跟随系统 / 浅色 / 深色；界面语言简体中文或 English | [设置与维护](./settings) |
| 项目主页入口 | 面板标题可跳转到项目主页 | — |

## 内核生命周期

| 能力 | 说明 | 文档 |
| --- | --- | --- |
| 启动 / 停止 / 重启内核 | 控制本机 `mihomo` 进程；状态显示运行中、启动中、已停止、异常 | [快速开始](./quick-start) |
| 启动前配置校验 | 启动前对当前 YAML 执行校验，失败时阻断启动并提示日志 | [配置与订阅](./configuration)、[常见问题](./troubleshooting) |
| 内核目录 | 运行时内核位于 `~/Library/Application Support/clashbar/core/mihomo` | [快速开始](./quick-start) |
| 在访达中打开内核目录 | 方便替换或检查二进制 | [设置与维护](./settings) |
| 升级 Core | 在内核运行中检查并更新 mihomo 内核（面板页脚） | [设置与维护](./settings) |
| 网络断开自动停核 | 检测到离线可停止内核，网络恢复后按设置自动再启动 | [设置与维护](./settings) |
| 内核自启 | 应用启动后自动拉起内核（设置开关） | [设置与维护](./settings) |
| 开机自启 | 登录 macOS 时自动打开 ClashBar | [设置与维护](./settings) |

## 工作目录一览

运行时根目录：`~/Library/Application Support/clashbar`

| 子目录 | 用途 |
| --- | --- |
| `config/` | 本地 YAML 与订阅结果（仅 `.yaml` / `.yml`，按名排序） |
| `core/` | `mihomo` 可执行文件 |
| `icon/` | 代理组图标磁盘缓存 |
| `ui/` | Mihomo External UI 静态资源（按配置由内核生成） |
| `logs/` | 运行与排障日志 |
| `state/` | 应用状态（建议由程序维护） |

发现规则与备份建议见 [配置与订阅](./configuration)。排障见 [常见问题](./troubleshooting)。设计初心与体积对比见 [关于](./about)。
