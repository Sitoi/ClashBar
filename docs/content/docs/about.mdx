ClashBar 是基于 [mihomo](https://github.com/MetaCubeX/mihomo) 的原生 macOS 菜单栏代理客户端，使用 SwiftUI + AppKit，面向轻量、稳定与可观测的日常使用。

## 设计初心

围绕两个关键词：**轻量** 与 **稳定**。

- **轻量化优先**：在打包 mihomo Core 的前提下，应用体积目标控制在 **15 MB 以内**。
- **可裁剪交付**：移除 Core 后，应用体积目标控制在 **3 MB 以内**，便于快速分发。
- **稳定性优先**：优先保证日常可用性与长期运行稳定，避免为短期功能堆叠牺牲可靠性。

首次安装见 [快速开始](/docs/quick-start)；完整产品能力见 [功能总览](/docs/features)；排障见 [常见问题](/docs/troubleshooting)。

## App 体积对比（macOS）

| 客户端 | 应用体积 | 相对 ClashBar（无 Core） |
| --- | ---: | ---: |
| ClashBar.app（No Core） | 2.7 MB | 1.0× |
| ClashBar.app（含 Core） | 14.2 MB | 5.2× |
| ClashMac.app | 75.2 MB | 27.8× |
| Clash Verge.app | 128.4 MB | 47.5× |
| Clash Party.app | 496.7 MB | 183.9× |
| Sparkle.app | 519.8 MB | 192.5× |

<Callout type="info" title="数据说明">
对比数据来自同一台 macOS 环境下 Finder 显示值。不同版本与构建方式会影响最终体积，以上用于说明轻量化设计方向，而非严格性能基准。
</Callout>
