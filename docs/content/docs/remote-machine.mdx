本机日常使用见 [日常使用](./daily-use)。需要时，也可把控制目标切到另一台已开启 External Controller 的 Mihomo 实例（旁路由、另一台 Mac 或服务器上的 mihomo）。

## 本机与远程

面板头部的机器切换器可以：

- 选择 **本地**（本机内核与本机配置目录）。
- 选择已添加的 **远程** 机器（按名称显示，副标题为地址）。
- 打开 **管理远程机器** 进行增删改。

远程条目会显示连接探测状态（检测中 / 已连接及版本 / 失败原因等）。

## 添加与编辑

在「管理远程机器」中：

1. 点击 **添加机器**。
2. 填写 **名称**、**主机地址**、**端口**、可选 **密钥**（对应 remote controller secret）。
3. 预览连接串确认无误后 **保存**。

编辑、删除在列表中对应操作完成。请只添加你有权管理、且网络可达的实例；密钥请勿写进公开文档或截图。

## 远程模式下的能力边界

| 仍可用（通过远程 API） | 通常仅本机 / 受限 |
| --- | --- |
| 查看与切换代理组、模式 | 导入/删除本机配置文件 |
| 规则、连接、日志（远程侧） | TUN 权限与 TUN 开关（本地内核能力） |
| 部分内核设置 patch（视 API） | 本机开机自启、本机配置目录访达操作 |
| 系统代理可指向远程端口 | 需自行保证远程地址从本机可达 |

当系统代理指向远程内核时，界面会提示确认远程地址可达。远程配置列表中的项可能标记为不可在本机侧变更。

## 终端命令

**复制终端命令** 与 **复制当前端点命令** 会按当前控制目标生成环境变量式代理命令：

- 本机：指向本机监听端口。
- 远程：指向当前远程端点（仍取决于你的网络与该实例是否允许你的客户端接入）。

## 安全建议

- 不要对公网裸露无认证的 External Controller。
- 使用 secret，并限制防火墙来源 IP。
- 在不信任的网络上慎用「系统代理 → 远程」。
