ClashBar 是面向 macOS 菜单栏的 [mihomo](https://github.com/MetaCubeX/mihomo) 客户端：把配置、节点、分流、连接与日志收进一个轻量原生面板。

按使用阶段阅读，比按功能名跳转更省事：

1. **装好并能连上** → [快速开始](/docs/quick-start)
2. **了解有哪些能力** → [功能总览](/docs/features)
3. **管好配置与订阅** → [配置与订阅](/docs/configuration)
4. **日常切节点、看规则与日志** → [日常使用](/docs/daily-use)
5. **接管系统流量** → [系统代理与 TUN](/docs/network-mode)
6. **偏好与维护** → [设置与维护](/docs/settings)
7. **多网络 / 远程控制** → [SSID 策略](/docs/ssid-strategy)、[远程机器](/docs/remote-machine)
8. **出问题再查** → [常见问题](/docs/troubleshooting)

设计初心、体积对比与社区见 [关于](/docs/about)。

同一时间只保留一个 mihomo / Clash 系客户端接管系统代理。请将 `ClashBar.app` 放入「应用程序」，并在登录项中允许后台活动。完整清单见 [快速开始 · 安装与使用前注意事项](/docs/quick-start#安装与使用前注意事项)。
