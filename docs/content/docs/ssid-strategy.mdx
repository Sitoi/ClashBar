---
title: SSID 策略
description: 按当前 Wi‑Fi 自动切换 ClashBar 配置。
---

在已经会 [导入与切换配置](./configuration) 之后，可以用 SSID 策略在换 Wi‑Fi 时自动换配置，适合「家里 / 公司 / 公共网络」使用不同订阅或规则。

入口在**节点**页的配置菜单（与「切换配置」同一区域）。

## 开启自动切换

1. 打开菜单栏面板，进入配置相关菜单。
2. 选择 **开启 Wi‑Fi 自动切换**。
3. 若系统尚未授权读取 Wi‑Fi 信息，按提示 **请求 Wi‑Fi 权限**（macOS 通过定位相关权限暴露当前 SSID）。

关闭时选择 **关闭 Wi‑Fi 自动切换**。关闭后不会再根据 Wi‑Fi 切换配置，已有绑定关系仍保留，可再次开启后继续使用。

## 绑定与解绑

1. 先 **开启 Wi‑Fi 自动切换**。
2. 连接目标 Wi‑Fi。
3. 在目标配置上使用 **绑定当前 Wi‑Fi：\<名称\>**（文案随当前 SSID 变化）。
4. 解除时使用 **解绑当前 Wi‑Fi** 或针对某 SSID 的 **解绑 Wi‑Fi：\<名称\>**。

绑定成功后，配置项旁会显示已绑定的 Wi‑Fi 标签。之后每次连上该网络，ClashBar 会切换到对应配置（目标配置仍存在时）。

## 权限与限制

| 状态 | 含义 |
| --- | --- |
| 未请求 / 已拒绝 / 受限制 | 无法可靠读取 SSID，自动切换不会生效 |
| 定位服务未开启 | 系统关闭了定位服务，需在系统设置中打开 |
| 已授权 | 可以绑定与自动切换 |
| 未连接 Wi‑Fi | 无法完成「绑定当前 Wi‑Fi」 |

- 自动切换依赖本机 Wi‑Fi 与本地配置列表；远程控制目标下请优先确认你改的是本机配置策略。
- 若绑定的配置文件已被删除，命中该 SSID 时会跳过切换并记入日志。

## 排障

- 切换不生效：确认已开启自动切换、权限为已授权、目标配置仍在列表中。
- 看不到当前 SSID：先请求权限，并确认系统定位服务开启、已连接 Wi‑Fi。
- 日志中可搜索与 SSID 策略相关的记录（绑定、解绑、切换、权限不足等）。
