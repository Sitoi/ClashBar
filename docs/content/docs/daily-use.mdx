title: 日常使用

---

完成 [快速开始](/docs/quick-start) 并选好配置后，日常操作都在菜单栏面板里完成。

打开 ClashBar 图标后，面板提供「节点」「分流」「连接」「日志」和「设置」五个标签。面板头部可**固定**面板、启动/停止内核，并切换本机或[远程机器](/docs/remote-machine)。完整能力表见 [功能总览](/docs/features)；系统代理与 TUN 见 [系统代理与 TUN](/docs/network-mode)。

## 功能导航（面板一览）

| 标签 | 常见能力 |
| --- | --- |
| **节点** | 实时速率、连接数、内存等运行态、配置入口、系统代理、代理组/提供者、模式切换 |
| **分流** | 规则列表与统计、搜索/按策略分组、刷新 |
| **连接** | 活动连接过滤、关闭单条/全部、复制 Host 等 |
| **日志** | 级别与来源过滤、关键词检索、复制与清空 |
| **设置** | 语言、外观、状态栏样式、端口、allow-lan / IPv6 / 日志级别、维护操作 |

## 节点与代理组

「节点」标签展示代理提供者和代理组：

- 在代理组中选择需要使用的节点或策略。
- 使用「延迟测试」检查节点可用性。
- 可选择按延迟排序节点，或显示/隐藏配置中标记为 hidden 的代理组。
- 代理提供者支持手动刷新；订阅信息会显示已用流量、总流量和到期时间（若提供者返回这些信息）。
- 配置菜单中可切换配置、导入订阅，以及配置 [SSID 策略](/docs/ssid-strategy)（按 Wi‑Fi 自动切换配置）。

顶部模式切换包括：

- **规则**：请求按配置中的规则匹配代理组。
- **全局**：所有流量使用当前全局策略。
- **直连**：所有流量直接连接。

状态栏与面板可展示实时上下行速率；面板内另有流量曲线，便于观察近期负载。

## 分流规则

「分流」标签列出 Mihomo 当前加载的规则。你可以按目标、类型或策略搜索，并按策略分组查看。它适用于确认某域名、IP 或规则集最终会走哪个代理组。

## 连接

「连接」标签展示正在活动的网络请求，可按域名或 IP 搜索，并按 TCP、UDP 等传输类型筛选。支持按创建时间或上传、下载、总流量排序。

遇到某个网站无法访问时，先在这里确认请求实际匹配到的代理组，再回到节点或规则调整。

## 日志

「日志」标签用于诊断应用和 Mihomo：

- 按信息、警告或错误等级过滤。
- 按 ClashBar 或 Mihomo 来源过滤。
- 搜索、复制、清空日志，或复制单条完整日志。

日志中包含启动失败、订阅下载失败、配置校验错误、GEO/MMDB 下载与 TUN 授权问题等关键线索。

## 终端代理命令

在「快捷操作」中可复制终端代理命令（以及「复制当前端点命令」）。将其粘贴到终端后，该终端会话的命令行工具可通过当前控制目标的代理端口访问网络。离开当前终端或取消环境变量后即失效。

对应快捷键见下方「键盘快捷键」。设置项（自启、状态栏样式、端口、缓存清理等）见 [设置与维护](/docs/settings)。

## 键盘快捷键

下列快捷键在 **ClashBar 作为前台应用** 时生效（通过 macOS 菜单栏命令注册）。从菜单栏点开面板后，若焦点仍在其它 App，部分快捷键可能不会触发——可先点一下面板或 Dock 中的 ClashBar。

### 快捷操作

| 操作 | 快捷键 | 说明 |
| --- | --- | --- |
| 切换系统代理 | <kbd>⌘S</kbd> | 开启或关闭 macOS 系统代理 |
| 切换 TUN | <kbd>⌘E</kbd> | 开启或关闭 TUN；不可用时菜单项会禁用 |
| 运行模式 Rule / Global / Direct | <kbd>⌃⌘1</kbd> / <kbd>⌃⌘2</kbd> / <kbd>⌃⌘3</kbd> | 切换代理模式；不可用时菜单项会禁用 |
| 复制终端命令 | <kbd>⌘C</kbd> | 复制本机代理环境变量命令 |
| 复制当前端点命令 | <kbd>⌘⌥C</kbd> | 按当前控制端点（本机或远程）生成命令 |
| 重新加载配置 | <kbd>⌘R</kbd> | 让运行中内核重读当前配置 |
| 启动 / 重启内核 | <kbd>⌘⇧R</kbd> | 主内核操作；**远程目标下禁用** |
| 停止内核 | <kbd>⌘⇧.</kbd> | 停止本机内核；**远程目标下禁用** |

### 面板标签

| 标签 | 快捷键 |
| --- | --- |
| 节点 | <kbd>⌘⌥1</kbd> |
| 分流 | <kbd>⌘⌥2</kbd> |
| 连接 | <kbd>⌘⌥3</kbd> |
| 日志 | <kbd>⌘⌥4</kbd> |
| 设置 | <kbd>⌘⌥5</kbd> 或 <kbd>⌘,</kbd> |

<Callout type="warn" title="关于 ⌘C">
应用在前台时，<kbd>⌘C</kbd> 绑定为「复制终端命令」，会覆盖系统「编辑 → 复制」。若需要标准复制，请使用右键菜单或在其它应用中操作；端点命令请用 <kbd>⌘⌥C</kbd>。
</Callout>

<Callout title="远程模式">
连接[远程机器](/docs/remote-machine)时，启动/重启/停止本机内核的快捷键不可用；系统代理与 TUN 仍按当前能力边界执行，详见 [系统代理与 TUN](/docs/network-mode)。
</Callout>
